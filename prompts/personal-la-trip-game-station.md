# Personal 페이지 이어서 작업: LA 여행 일정 뷰 + 게임 스테이션(엘사 모드)

Personal 페이지(지구 화면)에서 이어서 작업해 주세요. 추가할 기능은 두 가지입니다.

- **기능 A — 예정된 여행(LA):** 지구에 LA를 예정된 여행으로 표시 → 불러오기 확인 → 로딩 → LA 지도와 일차 카드 → 일차를 고르면 경로가 시뮬레이션처럼 재생되고 옆에 그날 정산이 함께 표시됨
- **기능 B — 게임 스테이션:** 지구 화면 오른쪽 위에서 게임 스테이션으로 이동 → 게임 목록 → "엘사"를 고르면 노래가 나오고 손동작으로 눈줄기와 눈사람을 만듦

아래 화면 문구(따옴표 안 한국어)는 사용자가 정한 것이니 그대로 써 주세요.

1. **Personal 페이지와 지구 화면 코드 위치를 먼저 찾으세요.**
   `minjikim-18/minjikim.github.io`의 `main` 브랜치(커밋 `9242b15`)에는 학술 홈페이지(`index.html`, `stylesheet.css`)만 있고 Personal 페이지, 지구 화면, LA 폴더는 없습니다. 지금 세션의 작업 폴더나 다른 브랜치에서 찾고, 없으면 추측해서 새로 만들지 말고 사용자에게 위치를 물어보세요.

## 1. 기능 A — 예정된 여행(LA)

### 화면 흐름

```
지구 화면 (LA = 예정된 여행 마커)
  └─ "예정된 여행을 불러오시겠습니까?"  [네] [아니요]
        ├─ 아니요 → 창 닫고 지구 화면 유지
        └─ 네 → 로딩: 동그란 스피너 + "여행 동선 최적화중입니다"
                 └─ 지구가 LA로 회전·확대, LA 활성화
                       └─ LA 클릭 → LA 지도 + 1일차 / 2일차 / 3일차 카드
                             └─ 1일차 카드 선택 → 경로 시뮬레이션 재생 + 옆에 하루 정산
```

### A-1. 지구에 LA를 예정된 여행으로 표시

- LA 좌표(34.0522, -118.2437)에 마커를 두고 "예정된 여행 · LA"라고 라벨을 붙입니다.
- 이미 다녀온 곳 마커가 있다면 그것과 구분되게 합니다(예: 펄스 링, 다른 색).

### A-2. 불러오기 확인과 로딩

- 확인 창 문구: **"예정된 여행을 불러오시겠습니까?"**, 버튼은 **"네"** / **"아니요"**.
- 뜨는 시점: Personal 페이지에 들어와 지구가 나타난 직후 한 번. "아니요"를 누른 뒤에는 LA 마커를 누르면 다시 묻습니다.
- "네"를 누르면 화면 전체 로딩 오버레이: 회전하는 원형 스피너 + **"여행 동선 최적화중입니다"**.
  - 이 시간 동안 실제로 일정 데이터를 읽고 경로 좌표를 준비합니다.
  - 준비가 빨리 끝나도 최소 2초는 보여 줍니다(연출이 눈에 보여야 함).
- 로딩이 끝나면 지구가 LA 쪽으로 돌아가며 확대되고, LA 마커가 누를 수 있는 상태가 됩니다.

### A-3. LA 지도와 일차 카드

- LA를 누르면 LA 지도 화면으로 전환합니다. 지구로 돌아가는 버튼을 둡니다.
- **1일차 / 2일차 / 3일차** 카드를 만듭니다. 일수는 `LA` 폴더 데이터를 따릅니다(3일이 아니면 데이터 기준).
- 카드에는 날짜, 대표 장소 2~3곳, 방문 장소 수, 그날 지출 합계를 넣습니다.
- 지도는 API 키 없이 동작해야 합니다. 기존에 쓰는 지도 라이브러리가 없다면 Leaflet + OpenStreetMap 계열 타일을 권장합니다.

### A-4. 경로 시뮬레이션

일차 카드를 선택하면 그날 동선이 "슝슝" 지나가는 느낌으로 재생됩니다.

- 이동 마커가 출발지에서 시작해 경로를 따라 움직이고, 지나간 구간에 선이 그려집니다.
- 장소에 도착하면 핀이 톡 튀어나오며 순번, 장소 이름, 시간이 표시되고 0.6~1초 정도 머뭅니다.
- 하루 전체 재생 길이는 15~25초 정도. 컨트롤은 재생/일시정지, 다시 보기, 배속(1x/2x).
- 재생 중 다른 일차 카드를 누르면 지금 재생을 멈추고 그 일차로 바뀝니다.
- 방문 순서는 `LA` 폴더에 적힌 순서를 따릅니다. 순서가 없는 날만 가까운 순으로 정렬합니다.
- 경로 선은 도로 경로를 미리 계산해 정적 JSON으로 저장해 두고 씁니다. 페이지가 열릴 때 길찾기 API를 호출하지 않습니다. 미리 계산하기 어려우면 장소 사이를 부드러운 곡선으로 잇습니다.
- `prefers-reduced-motion` 설정이면 애니메이션 없이 완성된 경로를 바로 보여 줍니다.

### A-5. 하루 정산 (지도 옆 패널)

- 지도 옆(모바일에서는 지도 아래)에 선택한 일차의 정산 패널을 둡니다.
- 지출 항목 목록: 장소 또는 항목 이름, 분류(식비, 교통, 입장료, 쇼핑, 숙박 등), 금액.
- **시뮬레이션과 연동:** 이동 마커가 장소에 도착하는 순간 그 장소의 지출이 목록에 추가되고 합계 숫자가 올라갑니다.
- 패널 아래에 하루 합계와 분류별 소계를 둡니다. 동행 인원이나 결제한 사람 정보가 데이터에 있으면 1인당 금액(또는 누가 누구에게 얼마)을 함께 표시합니다.
- 통화는 데이터에 적힌 대로 표시합니다. 원화 환산을 넣는다면 환율을 데이터 파일에 상수로 적고 "약"을 붙입니다.
- 비용 정보가 없으면 금액을 지어내지 말고 "미정"으로 두고 사용자에게 요청하세요.

### 데이터 구조

`LA` 폴더 내용을 정리한 JSON 파일 하나를 만들고 화면은 그 파일만 읽게 합니다. 아래는 구조 예시이며 값은 자리 표시입니다.

```json
{
  "trip": "LA",
  "currency": "USD",
  "days": [
    {
      "day": 1,
      "date": "YYYY-MM-DD",
      "stops": [
        {
          "name": "장소 이름",
          "lat": 0, "lng": 0,
          "time": "HH:MM",
          "memo": "",
          "costs": [{ "label": "항목", "category": "식비", "amount": 0 }]
        }
      ],
      "route": [[0, 0], [0, 0]]
    }
  ]
}
```

## 2. 기능 B — 게임 스테이션

### B-1. 진입과 게임 목록

- 지구 화면 **오른쪽 위**에 "게임 스테이션" 버튼을 둡니다. 누르면 게임 스테이션 화면으로 넘어가고, 뒤로 가기로 지구에 돌아옵니다.
- 게임 스테이션에는 게임 카드가 여러 개 보입니다. 지금 실제로 동작하는 것은 **"엘사"** 하나이고, 나머지 칸은 "준비 중" 카드로 채웁니다.

### B-2. 엘사 모드 시작

"엘사" 카드를 누르면:

- 카메라 권한을 요청하고, 웹캠 영상을 거울 모드로 화면 가득 띄운 뒤 그 위에 효과용 캔버스를 겹칩니다.
- 노래 "Let It Go"가 재생됩니다. 브라우저 자동 재생 정책 때문에 카드 클릭 이벤트 안에서 재생을 시작해야 합니다. 음소거 버튼을 둡니다.
- 화면 구석에 손동작 두 가지를 그림이나 짧은 문구로 안내합니다.
- 게임에서 나가면 카메라 스트림과 음악을 모두 정지합니다.

### B-3. 손동작 1 — 눈줄기

- **동작:** 손등이 바닥을 향하게(손바닥이 위) 한 채로, 주먹을 쥐었다가 손가락을 쫙 폅니다.
- **반응:** 펴는 순간 손바닥 위에서 눈줄기가 위쪽으로 "슈웅" 솟구칩니다. 손을 편 채로 있으면 계속 나오고 손을 움직이면 따라옵니다. 주먹을 쥐거나 손을 뒤집으면 서서히 사라집니다.
- **모양:** 흰색~하늘색 입자와 반짝이는 눈 결정. 위로 갈수록 퍼지고 흩날리며 떨어집니다.
- **판정 힌트:**
  - 손 인식은 MediaPipe HandLandmarker(21개 랜드마크) 권장.
  - 손가락 펴짐은 손끝-손목 거리와 손가락 뿌리-손목 거리의 비율(또는 관절 각도)로 판단.
  - 주먹을 0.15초 이상 유지 → 0.5초 안에 다섯 손가락이 펴지면 발동.
  - 손바닥 방향은 손목(0), 검지 뿌리(5), 새끼 뿌리(17)로 만든 법선 벡터로 구합니다. 왼손/오른손에 따라 부호가 반대이고, 거울 모드에서는 왼손·오른손 판정이 뒤바뀌니 주의하세요.
  - 정면 웹캠에서는 손바닥이 위를 향하면 손이 옆모습으로 보여 인식이 흔들립니다. 허용 각도를 넉넉히(위쪽 기준 ±50° 정도) 잡고, 몇 프레임 평활화와 히스테리시스를 넣으세요.

### B-4. 손동작 2 — 눈사람

- **동작:** 검지만 펴서 바닥을 가리킨 채로 손끝으로 원을 두 바퀴 그립니다.
- **반응:** 손끝 아래 바닥에 눈보라가 소용돌이치고, 눈덩이가 아래부터 쌓여 눈사람이 완성된 뒤 통통 튀며 인사합니다. 한 바퀴 돌 때마다 소용돌이가 커져서 진행 상황이 보이게 합니다.
- **눈사람 디자인:** 올라프처럼 귀엽고 익살스러운 분위기의 눈사람을 코드(SVG 또는 캔버스)로 직접 그린 오리지널 디자인으로 만듭니다. 디즈니 공식 이미지나 캐릭터 그림을 가져다 쓰지 않습니다.
- 눈사람은 여러 개 만들 수 있고, 5개를 넘으면 가장 오래된 것이 녹아 사라집니다.
- **판정 힌트:**
  - 검지만 펴짐 + 검지 방향(뿌리→끝)이 화면 아래쪽이면 "바닥을 가리킴".
  - 바닥을 향해 수평으로 원을 그리면 카메라에는 납작한 타원으로 보입니다. 최근 궤적의 중심을 기준으로 손끝 각도를 누적해 약 660° 이상(두 바퀴에 여유를 둔 값)이 3~4초 안에 쌓이면 발동.
  - 도는 방향이 바뀌면 누적을 초기화하고, 너무 작은 원(반경 기준 미만)은 무시합니다.

### B-5. 공통

- **대체 조작:** 카메라가 없거나 권한을 거부한 경우 안내 문구를 보여 주고, 마우스/터치로도 할 수 있게 합니다(길게 누르면 눈줄기, 원을 두 바퀴 그리면 눈사람).
- **디버그 모드:** 주소에 `?debug=1`을 붙이면 랜드마크와 현재 판정 상태(주먹/폄, 손바닥 방향, 누적 각도)를 화면에 표시합니다. 임계값 조정에 씁니다.
- **구조:** 손동작 판정은 "랜드마크 입력 → 이벤트 출력" 순수 함수로 분리해, 녹화한 랜드마크 값으로 카메라 없이 테스트할 수 있게 합니다.

### B-6. 음악과 저작권, 개인정보

- "Let It Go" 음원 파일(mp3 등)을 리포에 넣지 마세요. 공개 GitHub Pages라서 저작권 음원을 재배포하는 것이 됩니다.
- 공식 유튜브 영상을 YouTube IFrame Player API로 임베드해 재생하세요. 영상 ID는 지어내지 말고, 공식 채널 업로드인지 확인하거나 사용자에게 받으세요.
- 임베드가 막힌 영상이면(플레이어 오류 101/150) "YouTube에서 열기" 링크로 대체하고, 게임은 음악 없이도 동작해야 합니다.
- 엘사 모드의 화면 요소(배경, 카드 그림, 효과)는 눈·얼음 테마로 직접 만들고 디즈니 이미지나 로고는 쓰지 않습니다.
- 손 인식은 전부 브라우저 안에서 처리합니다. 카메라 영상을 서버로 보내거나 저장하지 않습니다.

## 3. 기술 제약

- GitHub Pages 정적 사이트입니다. 서버, API 키, 빌드 과정 없이 동작해야 합니다.
- 외부 라이브러리는 CDN에서 버전을 고정해 불러옵니다.
- 카메라(`getUserMedia`)는 HTTPS 또는 `localhost`에서만 동작합니다.
- 모바일 화면에서는 지도와 정산 패널을 세로로 쌓습니다.
- 공개 사이트이므로 숙소 주소, 예약 번호, 항공편 번호 같은 민감한 정보는 페이지와 JSON에 넣지 마세요. `LA` 폴더 원본에 있으면 빼고, 뺀 항목을 보고에 적어 주세요.
- 이번 작업 범위는 Personal 페이지와 새로 추가하는 파일입니다. 학술 홈페이지(`index.html`) 내용은 바꾸지 않습니다.

- [ ] 장소 도착과 동시에 정산 패널에 항목이 추가되고 하루 합계가 `LA` 폴더 금액과 일치한다.
- [ ] 지구 화면 오른쪽 위 버튼으로 게임 스테이션에 들어가고 돌아올 수 있다.
- [ ] "엘사" 선택 시 카메라와 음악이 시작되고, 나가면 둘 다 정지한다.
- [ ] 손바닥을 위로 하고 주먹→폄 동작에 눈줄기가 나온다.
- [ ] 검지로 바닥을 가리키고 두 바퀴 돌리면 눈사람이 생긴다.
- [ ] 카메라가 없어도 마우스/터치 대체 조작으로 두 효과를 볼 수 있다.
- [ ] 브라우저 콘솔에 오류가 없다.

브라우저에서 직접 열어 위 흐름을 확인해 주세요. 실제 손으로 하는 동작 인식은 자동으로 검증하기 어려우니, 녹화한 랜드마크 값으로 판정 함수를 테스트하고, 실제 손 테스트가 필요한 부분은 "사용자 확인 필요"로 구분해 보고해 주세요.

## 5. 사용자 요청을 이렇게 해석했습니다

사용자가 따로 말하지 않으면 아래 해석대로 진행하고, 보고할 때 이 목록을 함께 알려 주세요.

1. 불러오기 확인 창은 Personal 페이지에 들어오면 자동으로 한 번 뜬다.
2. "네"/"아니요"는 사용자가 직접 누르는 버튼이다(자동으로 눌리는 연출이 아님).
3. 로딩이 끝난 뒤 지구가 LA로 이동하고, LA를 눌러야 지도가 열린다.
4. "정산"은 그날 지출 요약이다. 동행 정보가 있을 때만 나눠 내기 계산을 더한다.
5. 눈줄기는 손바닥에서 위쪽으로 솟는다.
6. 게임 목록에서 "엘사" 외의 카드는 "준비 중" 표시다.
